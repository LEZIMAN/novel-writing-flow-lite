# AI 小说写作工作流

> Lite v0.3 · 2026-11-19

这版 Lite 带你从前情和本场要求走到正文首稿，再按复核意见修订并复查。场景卡约定这场发生什么、停在哪里，通用执行卡约定怎么写。对白和动作需要先排顺时，可以在中间加一份剧本。

1. 用上一段前文和本场要求[搭场景卡](.agents/skills/lite-scene-card/SKILL.md)。也可以直接填[章节工作包](模板/章节工作包.md)。
2. 需要先排对白和动作时，[写一份可选剧本](.agents/skills/lite-scene-script/SKILL.md)，再选定一个接入版。
3. 把当前状态、场景卡、[通用执行卡](模板/通用执行卡.md)和选定的剧本（如有）交给[正文入口](.agents/skills/lite-draft/SKILL.md)，保存首稿。
4. 把首稿与本轮材料交给独立于执笔的上下文，按[复核入口](.agents/skills/lite-review/SKILL.md)写出事实问题、表达警告和解释警告。
5. 按[修订入口](.agents/skills/lite-revise/SKILL.md)落实意见，另存修订稿，再交独立上下文复查。用[复核与修订记录](模板/复核与修订记录.md)保留改法、前后文本和实际结论。

第一次试，可以沿着[《窗边猜牌》](示例/窗边猜牌.md)看前情怎么变成场景卡，剧本怎么写成正文，再看[同场的复核与修订示范](示例/窗边猜牌-复核与修订.md)。按[工作流](工作流.md)换成自己的材料。已有首稿时可直接从复核开始。

建议用能直接读取项目文件的工具，把文件路径和本场要求交给它即可。网页聊天端可手动贴指令和材料试用，运行效果不作保证。

工具支持独立会话或子智能体时，可以按工作流把材料交接到复查结束。只有一个会话时，可以先准备好复核任务和材料，再交给另一个会话。记录实际完成到哪一步，待作者裁定的问题随稿交付。

## 更新计划

我会每周补充一组功能，直到 Lite 的内容与完整版一致。本次补独立复核、定点修订和复查，下一组接入对白和战斗组件。

v0.3 新增两个技能入口、一份复核与修订记录模板，以及同场的改前改后与复查示范。复核同时看事实与读感，保留需要作者判断的警告。示范由维护者编写，实际试跑时另记所用模型、上下文和结果。

附了一段实测记录，可以对照如何删去突兀的来回和重复解释，以及修后怎么查出漏掉的收尾动作。[警告处理实验节选](示例/实验节选-警告怎么处理.md)

想看这套流程在小说里怎么用，可以到我的知乎主页读「AI 小说工程化实践」系列。我在那里分享长篇续写、对白和叙事节奏的改稿过程。推荐从[《火车都快炸了，怎么还在开会》](https://zhuanlan.zhihu.com/p/2100006685075162653)读起，里面有战斗对白和关键动作的改前改后对照。

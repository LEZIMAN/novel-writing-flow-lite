# AI 小说写作工作流

> Lite v0.1 · 2026-11-03

这套流程把一章的设计、成稿和验收拆开。用当前状态交代前情，用场景卡设计本章，用通用执行卡约定写法。复杂场面可以先写剧本，再由正文作者写出人物经历。

1. 复制[章节模板](模板/章节工作包.md)，填写当前状态和场景卡。把[通用执行卡](模板/通用执行卡.md)随本章材料发给执笔者。
2. 简单场面可直接写正文。交流复杂或有多人行动时，先写剧本并选定唯一接入版。交战或复杂协作先校核时空。
3. 让独立会话读实际保存稿，分别检查事实和读感。修后回看邻接段落，作者验收后更新交接。
4. 可先读[窗边猜牌示例](示例/窗边猜牌.md)，再按[完整流程](工作流.md)跑自己的章节。

支持手工交接，也可将材料交给能读取项目文件的写作工具。用聊天窗口时，发送文件内容或实际附件。模型和档位按任务、额度及试写表现选择。

# 复核与复查

## 首稿复核

1. 确认目标稿、实际审阅范围和输出位置。读取同一时点的当前状态、场景卡、[通用执行卡](../../../模板/通用执行卡.md)、作者本轮要求，以及采用的剧本（如有）。补读影响本场的已确认前文。使用独立于执笔的会话或上下文，记录实际执行方式。
2. 连读保存后的目标稿，检查事实、时序、人物所知、世界规则、关键位置和动作，以及场景卡约定的结果。每项发现引用原句和相关基准，存在不同读法时写清分歧。必要材料缺失时列待核实项。
3. 看实际交流、动作和段落怎样推进。阅读问题另列为表达警告，引用完整回合或相关前后句，说明哪里拗口、重复、反应接不上，或关键变化缺少展开。能定位时记录首次出现于场景卡、剧本还是正文。
4. 在实际审阅范围内逐处列出解释性表达，包括人物推断、动机说明和叙述总结。可合并连续解释，引用足够上下文，并在报告里加粗解释部分，写明可保留、建议修订或待作者裁定。必要的说明可以保留。警告的处理依据是具体作用。
5. 按[复核与修订记录](../../../模板/复核与修订记录.md)交付。结论用通过、定点修订清单或须重排场景，另列影响结论的待核实材料。结构、关键因果或空间条件需要重排时，指出应回到场景卡处理的部分。

事实与连续性分四级记录。严重矛盾列必修，很可能不一致附证据建议修订，可能隐患交作者裁定，可以成立的留白注明依据。表达和解释警告分别记录处理建议，警告数量只反映本次发现。

报告与正文分开保存。下一步将目标稿、本轮报告、作者补充意见和实际基准交给[修订入口](../lite-revise/SKILL.md)。

## 修后复查

读取本轮基准、原报告与改法清单，以及从保存后的修订稿提取的实际文本。改段的前后快照须包含触发它的问话或动作，以及后续回应。能访问文件时，读取实际保存稿核对。

逐项确认改法落实、事实与知识边界保留、问答和动作仍能接上。删除解释或压缩段落时，核对承担实质作用的动作、条件和人物决定。用前后段落说明读感的收益与代价。检查本轮范围内的剩余表达和解释警告，记录已关闭、仍存、重新出现、新增或待核实。

复核者只返回结论和证据，由修订执行者处理实际改文。剩余事实错误继续修复并复查受影响处。表达与解释警告在同一轮集中打回正文一次，复查后列出保留项及理由，下一轮是否继续润色按作者要求决定。报告结论覆盖实际读取的范围。

工具可以把材料交给独立会话或子智能体时，使用该能力完成复核。需要用户另开会话时，交付完整任务和实际材料，并在记录中标明待独立复核。执行者自查照实登记。

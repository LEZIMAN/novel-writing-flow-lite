# 按意见修订

1. 读取最新目标稿、作者本轮要求、对应的[通用执行卡](../../../模板/通用执行卡.md)及本轮复核报告。涉及前后承接时读取同一时点状态、场景卡和选定剧本。核对目标文件，保留原首稿，修订稿另存。
2. 在[复核与修订记录](../../../模板/复核与修订记录.md)里列短清单，写明原句锚点、要解决的问题、具体改法和必须保留的事实、人物所知、决定、动作及停止位置。作者已提供改文时用其文本。明确的改法直接执行，缺少会改变剧情的决定时列出待裁定项，继续处理已有依据的部分。
3. 根据锚点连读上下文再修改。措辞问题可以改一句，接话断连要覆盖相关回合。场景条件或关键因果需要重排时，把依据交回场景卡设计。删去解释前，确认其中是否还有动作尚未传达的信息、顾虑或条件。
4. 保存后重新读取修订稿，逐项核对实际改文。连读触发改段的前句和其后的回应，检查指代、时序、知识、资源及动作能否接续。特别核对删段时有没有带走关键动作或决定。用实际前后句简记收益、代价和刻意保留项。
5. 按[复核入口](../lite-review/SKILL.md)的修后复查要求，交出本轮基准、原报告、改法清单，以及从实际保存稿提取的前后段落快照。提供目标文件和段落锚点，记录实际使用的独立上下文。工具支持时直接交接，需另开会话时提供可复制的任务与材料，状态记为待独立复查。
6. 接到反馈后，修复未落实项和新增问题，重新读取保存稿，并复查受影响处。表达和解释警告按本轮意见集中处理，复查后保留的项目写明理由。交付修订稿、复查结论和剩余事项，由作者决定采用的版本；采用后才把本场结果写入下一场的当前状态。

正文文件放标题和正文。报告、改法与复查结论写进同一份本轮记录。记录中的快照取自实际保存文件，最终结论注明实际完成的范围和待办。

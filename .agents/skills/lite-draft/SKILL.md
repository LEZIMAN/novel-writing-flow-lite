# 写正文首稿

1. 读当前状态、场景卡、[通用执行卡](../../../模板/通用执行卡.md)和作者指定的一份剧本（如有）。文件模式下检查输出位置，已有正文时另存首稿。
2. 从视角人物正在经历的事写起。保留场景卡规定的关键事实、人物所知、实质决定和停止位置。接入剧本时，把台词和动作放回完整段落，按视角和气口处理可调整的表达。
3. 写到约定的变化发生为止。交稿前对照场景卡确认视角、关键动作和结束状态。

交付正文首稿。正文文件只放标题和正文。文件模式下另告知文件位置，聊天模式下直接返回正文。

需要审核时，按[复核入口](../lite-review/SKILL.md)交给独立上下文，附保存稿和实际基准。执笔自查的结果按实际方式记录。

# 写可选剧本

1. 读本场当前状态、场景卡和作者指定的共用要求。先确认开场、视角、关键变化和停止位置。
2. 按场景顺序写实际台词和关键动作。让前一拍的话或动作引出下一拍，让人物的请求、犹豫或让步在交流中实际发生。
3. 把普通措辞、具体段落和感官细节留给正文阶段。需要正文保住的事实、台词、选择和动作，单独列在剧本后。缺失的关键条件回到场景卡确认。
4. 选定一份剧本作为[正文](../lite-draft/SKILL.md)的输入。在[章节工作包](../../../模板/章节工作包.md)登记接入版本，以及可以调整的部分。

交付一份剧本和简短的事实锁定清单。文件模式下保存剧本并报告位置，聊天模式下直接给剧本和清单。

# 搭场景卡

1. 读作者给出的本场任务、与本场同一时点的前文或起始设定，以及相关人物资料。续写时把前文已确认的事实和本场计划分开。
2. 按[章节工作包](../../../模板/章节工作包.md)填写当前状态和场景卡。当前状态记开场时在场的人、地点、各自知道的事和仍生效的限制。只摘本场会用到的内容。
3. 用几拍说明场面怎么变化。写清视角人物想做什么、碰到什么阻碍、作了什么选择，以及本场具体停在哪里。标明哪一拍值得展开、哪些过程可以略写。
4. 分清要保留的事实和可由执笔决定的细节。如果一个缺失条件会改变场面走向或结尾，列为待确认项。小场面可以直接进入正文，需要先排好对白与动作时可接[可选剧本](../lite-scene-script/SKILL.md)。

交付填好的当前状态与场景卡。文件模式下另存工作包并报告位置，聊天模式下直接给这两个部分。
